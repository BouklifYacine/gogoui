One package: the design tokens now ship inside `@gogoui/ui` (`@gogoui/ui/tokens.css`, `@gogoui/ui/theme.css`, still imported for you by `@gogoui/ui/styles.css`); `@gogoui/tokens` is no longer needed. Twelve charts drawn in SVG with motion, adapted from Arc UI: Sparkline, Gauge, BarChart, LineChart, DonutChart, ActivityHeatmap, Streamgraph, BrushChart, RidgelineChart, Treemap, WaffleChart and SlopeChart, each with a text alternative and keyboard reading. Fixed: the Calendar no longer breaks when it changes month.
